# VESPERA — The Poster for a Place That Isn't There

make.fun entry for `the-poster-for-a-place-that-i-2-20261121-0539`.

`main.py` (Python 3.13, PIL only, no network) draws a 1024x1024 travel
poster for **VESPERA** — a cliff town on a sea where the sun sets twice —
and writes it to `/output/entry.png`. One landmark (the lighthouse), one
promise (two suns over a calm sea), one name set large into the picture.

Run: `python3 main.py` (deterministic: two runs produce identical bytes).
